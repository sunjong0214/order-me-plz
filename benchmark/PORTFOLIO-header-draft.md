### 핵심 성과

- 리뷰 저장의 데드락과 통계 갱신 유실을 원인별로 분석하고 통계 모델 분리 + 원자 UPDATE로 제거. 같은 가게에 작성이 몰리는 부하(가게 3곳, 15분)에서 데드락 약 103만 건 → 0, 누락된 통계 갱신 약 15만 건 → 0, 성공 응답 p95 35.5–37.1ms
- 선착순 한정 수량 이벤트(재고 10만 개, 시도 약 23만 건)에서 재고 처리 3방식 × 동기·비동기를 비교. 재고 판정은 메모리 번호표로 정해 10만 건 확정 37.9초(DB 행 하나 약 90초), 매진 응답 p95 1.4ms, 초과 판매 0. 접수는 매진 전 거절이 없는 비동기를 택했다(동시 처리 상한으로 거절하는 동기는 상한을 130에서 190으로 올려도 재고가 남은 동안 약 0.6–1.5만 건을 돌려보냄). 대신 응답·확정은 상한 190 동기가 더 빨라, 접수 방식은 거절 0과 응답 속도 사이의 선택으로 적음. 동기와 처리량이 같음도 확인
- 가게 목록 캐시의 근거 없던 만료 시간(24시간)을 평점 허용 지연과 서비스 규모 재조회 부하로 계산해 5분으로 재산정하고, 즉시 반영이 필요한 값은 변경 시 무효화, 여러 키의 동시 만료(Jitter)와 인기 키 하나의 동시 로딩(sync)을 나눠 대응 (동시 미스 10건의 쿼리 10회 → 1회, 기능 테스트)
